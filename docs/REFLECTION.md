## 大纲

1. **Superpowers 技能价值盘点**
   - 哪些技能发挥了最大作用（brainstorming / writing-plans / TDD / subagent-driven / review 系列）？为什么？
   - 哪些"形式大于实质"？哪些环节流程成本高于收益？

2. **TDD 在 AI 协作下：阻碍还是放大器？**
   - 强制红-绿-重构对 subagent 产出质量的实际影响
   - "先写失败测试"是否真正发生过拦截作用（有无案例）

3. **Subagent 驱动工作流的自主运行边界**
   - subagent 能自主运行多久不偏离主题？偏离发生在什么任务形态？
   - 什么样的 task 颗粒度最优？（结合 PLAN 的 20 task 实际体验）

4. **SPEC / PLAN 质量与实现质量的关联**
   - 举一个"规约不清导致 subagent 偏离"的具体案例（若无，说明为什么没发生）
   - PLAN 中接口预定义（Interfaces 区块）是否真的减少了跨 task 不一致

5. **最有效的 prompt / context 策略**
   - 哪些 prompt 结构、context 注入方式最有效？为什么有效？

6. **凭据与分发两条工程要求带来的思考**
   - 迫使你想清楚了哪些原本会忽略的问题（威胁模型、目标机配置、容器限制……）

7. **重做的话会改变什么**
   - 选型、顺序、任务切分、文档时机等

8. **对 Superpowers 方法论的批判**
   - 它假设了什么（一次性上下文充足、人类审阅在环、任务可静态分解……）？
   - 这些假设在本项目里成立吗？哪些不成立？
